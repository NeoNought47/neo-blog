# import-obsidian 使用说明

把一篇 Obsidian 笔记变成网站文章。只处理格式，不改正文内容。

脚本：`scripts/import-obsidian.mjs`

## 一句话用法

先进项目目录：

```bash
cd /Users/neyonought/dev/neo-blog
```

再跑：

```bash
npm run import-obsidian -- "~/Documents/NeosRepo/笔记文件名.md" xiaodi-security-009 --date 2026-09-21 --posted 2026-09-23
```

中间那个 `--` 不能省，它告诉 npm 后面的东西是给脚本的参数。

## 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 笔记路径 | 是 | Obsidian 里 `.md` 文件的路径。可以用 `~` 表示用户目录。文件名里有空格、`&` 这些符号时**一定要加引号** |
| slug | 是 | 文章在网站上的名字，决定网址 `/posts/<slug>`。只能用小写字母、数字和 `-`，比如 `xiaodi-security-009` |
| `--date YYYY-MM-DD` | 否 | 页面上显示的日期，即「实际时间」。不写就用今天 |
| `--posted YYYY-MM-DD` | 否 | 内部发布日期，只用来排首页侧栏「最近更新」，页面上不显示。不写就不加这个字段，排序时回退到 `date` |
| `--force` | 否 | 同名文章已存在时才需要，加了会覆盖。不加的话脚本会拒绝执行，防止误删 |

**建议每次都写 `--date`。**不写时脚本取的是 UTC 时间的今天，在波士顿晚上 8 点以后跑，会变成明天的日期。

## 它会做什么

1. 笔记正文复制到 `src/content/posts/<slug>.md`
2. 笔记里 `![[1.png]]` 引用的图片复制到 `src/assets/posts/<slug>/`
   - 先在笔记所在的文件夹找，找不到再到整个 Obsidian 库里按文件名找，和 Obsidian 自己的规则一样
   - 文件名里的空格换成 `-`，比如 `4 1.png` 会变成 `4-1.png`，否则 Markdown 链接会断
3. `![[1.png]]` 改写成网站认识的 `![](../../assets/posts/<slug>/1.png)`
   - `![[1.png|300]]` 里的 `300` 是 Obsidian 的显示宽度，会被丢掉
   - `![[1.png|说明文字]]` 里的说明文字会保留成图片的 alt
   - 嵌入的是另一篇笔记而不是图片时，原样不动
4. 笔记自带的 Obsidian 属性（开头 `---` 包起来的那段）去掉，重新生成网站用的 frontmatter：

```yaml
---
title: "小迪安全 009：基础入门 - xxx、xxx"
titleEn: "XiaoDi Security 009: TODO"
date: 2026-09-21
posted: 2026-09-23
tags: ["Cybersecurity", "Learning Notes"]
---
```

5. 正文最上面加一行课程来源说明：「课程为小迪安全官方 2024 年上传，本文为个人学习笔记。」

### 标题是怎么来的

从笔记**文件名**自动生成。文件名是「小迪安全 008-基础入门-算法分析&传输加密」这种格式时：

- `-` 变成 ` - `
- `&` 变成 `、`
- 编号后面加中文冒号

结果是「小迪安全 008：基础入门 - 算法分析、传输加密」。

所以**文件名里的错字会原样进标题**。008 那篇文件名末尾是「逆向保护护」，标题里就多了一个「护」。

文件名不是这个格式时，标题就是文件名本身。

## 跑完之后必须手动做的

脚本结束时会打印生成了哪些文件、复制了几张图。然后打开生成的 `.md` 检查这几项：

1. **`titleEn` 里的 `TODO` 换成英文标题。**不换的话，英文界面下标题会直接显示 `TODO`。可以照着 007 的写法：`XiaoDi Security 007: Getting Started with ...`
2. **中文标题检查一遍错字**，因为它是从文件名来的
3. **如果脚本提示「这些图片没找到」**，说明 Obsidian 里引用了但文件夹里没有，这些引用会保持 `![[xxx.png]]` 原样，网站上会显示成文字。要么把图找回来重新跑（加 `--force`），要么手动删掉那几行
4. **不是小迪的笔记时**，标签和课程来源说明都是写死的，要手动改：
   - `tags:` 改成合适的标签
   - 删掉正文最上面那行 `<span class="post-note">…</span>`

## 然后上线

```bash
npm run build
```

最后一行看到 `Complete!` 才往下走。看到 `ERROR` 先别推，把报错拿去查。

```bash
git add .
```

```bash
git commit -m "新增小迪安全 009"
```

```bash
git push
```

推完一两分钟，Cloudflare 自动部署上线。

## 常见报错

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `用法: npm run import-obsidian -- ...` | 笔记路径或 slug 少了一个 | 检查两个都写了，而且 `--` 没漏 |
| `slug 只能是小写字母、数字和 -` | slug 里有大写、空格、中文或下划线 | 改成 `xiaodi-security-009` 这种 |
| `--date 格式应为 YYYY-MM-DD` | 日期写成了 `2026-9-21` 或 `2026/09/21` | 月和日都补两位：`2026-09-21` |
| `找不到笔记` | 路径不对，或者文件名有空格没加引号 | 整个路径用双引号包起来。可以把文件从 Finder 拖进终端，路径会自动填好 |
| `已存在：src/content/posts/xxx.md` | 同名文章已经导过一次 | 确认要覆盖就加 `--force`，否则换个 slug |
